# Decisiones DSP

## Alcance confirmado

- Salience armónica será el detector principal.
- YIN aportará contraste y confianza, especialmente ante errores de octava.
- La primera implementación será Kotlin puro; solo se migrará código nativo si un benchmark en dispositivo lo justifica.
- Rango: 40–1500 Hz. A4 fijo a 440 Hz.
- El estado «Afinado» entra en ±5 cents y sale al superar ±8 cents.

Los parámetros internos se validarán con corpus sintético reproducible. No se trasladará código ni pseudocódigo propietario.
